أنت الآن تعمل كـ CTO + Principal Software Engineer لمشروع AIX
(Artificial Intelligence eXperience).

نحن لا نريد إنشاء مشروع جديد.
نريد نقل النسخة الحالية العاملة من Replit إلى GitHub تمهيدًا لتطويرها محليًا عبر VS Code.

==================================================
🎯 الهدف
==================================================

اجعل المشروع جاهزًا للنقل الآمن والكامل إلى GitHub وVS Code
بدون فقدان أي كود أو إعداد أو ملف أو schema أو API أو functionality.

اعتبر النسخة الحالية من AIX هي النسخة المرجعية.

⚠️ لا تعيد بناء المشروع.
⚠️ لا تغير architecture.
⚠️ لا تحذف ملفات بحجة أنها غير مستخدمة.
⚠️ لا تغيّر الـdatabase schema إلا إذا كان ضروريًا للنقل.
⚠️ لا تضف Features جديدة.
⚠️ لا تصلح مشاكل غير مرتبطة بالنقل إلا إذا كانت تمنع التشغيل.
⚠️ لا تضع Secrets أو API keys أو passwords داخل GitHub.

==================================================
2. Git readiness
==================================================

جهز المشروع ليكون Git repository احترافيًا.

تحقق من:

.gitignore

وتأكد أنه يمنع:

.env
.env.*
node_modules/
dist/
build/
logs/
temporary files
Replit-specific secrets
local database files
editor files
OS files

لكن لا تمنع ملفات configuration الضرورية للمشروع.

أنشئ أو حدّث:

.env.example

بحيث يحتوي فقط على أسماء المتغيرات المطلوبة
بدون أي قيم سرية.
